# Synth PoC Achievements — moved

This file was the proof-of-concept write-up, and it read as current status.
Its headline, **"0.85x native code size — 15 % smaller than native"**, was
never measured: the native half of the comparison was an ESTIMATE (the table
column was headed "Native Est"). When the same comparison is run against a real
`arm-none-eabi-gcc -Os`, the ratio inverts. synth's output is larger than
native, not smaller (#1287, re-measured on the v0.68 base with
`python3 scripts/repro/parity_benchmark/run.py --only falcon_axis`). The
page's other figures, a "147 passing tests" count among them, were unpinned
snapshots of the same age. It had no compliance column either, which the
compliance envelope in `CLAUDE.md` requires of any comparison with native code.

Following the precedent of [`PROJECT_STATUS.md`](PROJECT_STATUS.md), the
restatement is deleted rather than re-synced. An estimate-based ratio should
not survive in any form. The narrative stays in git history (this path, before
v0.68).

Measured code quality lives in the sources of truth:

- **[`artifacts/parity-benchmark.md`](../../artifacts/parity-benchmark.md)** —
  synth AOT against native C/Rust at `-Os`, every row measured, with its
  provenance and the open gaps. Generated by
  `python3 scripts/repro/parity_benchmark/run.py --report`; do not hand-edit.
- **[`docs/status/FEATURE_MATRIX.md`](FEATURE_MATRIX.md)** — the generated
  capability matrix.
- **`artifacts/status.json`** — machine-derived counts, re-derived on every
  commit by the claim gate.
