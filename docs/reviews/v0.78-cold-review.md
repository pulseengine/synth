### Pass B — gate potency: 18 gates tested, 2 vacuous

Every new or changed gate was made to go red on demand, with each mutation
verified against a **backup copy** (not against HEAD) and every exit code read
**without a pipe**. 16 were potent. The two that were not:

**Vacuity 1 — one matcher served all four refusals.** `_refuses()` in
`shipped_feature_census.py` checked only that the message began `REFUSE:`, so the
four refusal assertions were interchangeable: each asserted *some* refusal fired,
not *this* one. Measured — deleting the empty-glob refusal outright left the
self-test **green at 39 assertions / 0 failures**, because the downstream
zero-reads refusal satisfied the matcher. An assertion named a refusal it was not
testing: a true statement about the wrong subject, in the file whose subject is
that class. Fixed by requiring a distinctive substring per call site, plus an
assert against an empty needle. **Re-proven:** the same deletion now reds the
assertion that names it.

**Vacuity 2 — the header's claim about its own wiring was false.** It said the
census "asserts nothing … so there is no expected value for CI to fail on beyond
the self-test", and only `--self-test` was wired. But `main()` returns 1 on any
UNDETERMINED flag, which *is* an expected value. Measured — deleting the whole
`MEASURE_ONLY`/`DIAG`/`SOLVER_BUDGET` bucketing moved the answer from 4 hidden
capabilities to 15 with 2 undetermined, and **CI stayed green because nothing ran
the census**. The census is now a required step.

Four further findings from the same pass:

- **A false number in a release artifact's own evidence field with nothing pinning
  it** — "(36 assertions)" against a live 39.
- **The guard did not transfer back to the file that motivated it.**
  `ci_citation_floor.py --self-test` had no assertion-count floor even though
  `shipped_feature_census.py` added exactly that guard *in the same release*,
  citing this file's lane (#1435) as precedent. Deleting one assertion took it from
  15 printed assertions to 14 with **rc=0**. `MIN_ASSERTIONS = 15` added, derived by
  *running* the self-test — a first attempt that regexed `ok(` returned 9 and its
  own sanity assertion caught it before anything was written.
- **A fixture that claimed to be live.** Relabelled a frozen sample with its
  capture date rather than re-syncing a figure that moves with the corpus.
- **An actionable message on an unreachable path.** `wide60_declines_…`'s tripwire
  carries "flip this test AND add wide60 to the execution differential", but
  `expect_err` panics first in the realistic case, so the operator never saw it.
  The instruction now rides on the reachable message too.
