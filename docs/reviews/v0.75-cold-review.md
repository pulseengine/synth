**Commit reviewed:** `959a6452` (round 1, both passes). Round 2 ran at `5d23bb89`,
the head of the round-1 corrections PR; that head is not an ancestor of the

## Round 1 — gate potency

**19 experiments, 8 caught, 10 MISSED.**

### The finding that refuted a sentence this release shipped

RQ-75-REPLAY shipped *"a nonce chosen for THIS run cannot appear in a
recording."* **FALSE.** `"freshness_" + token_hex(8)` is always exactly 26 bytes,
so the nonce is a **fixed-length byte patch** into a recorded `.strtab`: no
offsets move, no ELF library, no compiler. Paired with a **verbatim** replay —
real `.text`, so the decode check reads 1.00 on every leg — the adversary passed
the entire CI step: `ORACLE-EVIDENCE … mode=compiles floor=6 measured=9 exit=0`,
`#1318 CHECKS=12/12`, `RESULT: PASS`.

Reproduced independently at the correction: 200 draws of that expression give
exactly one length.

**Fix:** export names are now variable length and the *number* of exports varies,
all required present. The docstring explicitly does **not** claim
unforgeability — an adversary that correctly *rebuilds* a string table defeats
it — only that satisfying it requires constructing an ELF rather than patching
bytes at fixed positions.

### The control could not see its own mechanism being deleted

`replay_control_1318.py` asserted only *that* a refusal happened, never **which
mechanism** produced it: `expect` was used solely to build a filename. Commenting
out `freshness_probe()` left it green, because both adversaries were decode-caught
on the riscv leg — so adversary 1 supplied **zero** evidence about the probe it
existed to prove.

**Fix:** each adversary names its mechanism and the refusal is matched against
it; a third adversary (the fixed-offset patcher) is the regression test; and
adversary 1 replays **verbatim** objects so freshness is the only thing that can
catch it. Deleting the probe now reds twice — *"the gate is inert again"* and
*"refused, but by the WRONG MECHANISM"*.

### FLOORBIND checked consistency, not adequacy

Replacing `FIXTURES` with three copies of one fixture leaves
`len(FIXTURES) * len(ARGVALS)` unchanged. Five independent gates ran green — the
oracle, `check_floor_binding`, the CI emulation-floor equality, `claim_check` at
75/75, and the generator's own `--check` — while two thirds of the corpus stopped
being tested, and the lost shapes were exactly v0.74's additions.

**Fix:** `REQUIRED_SHAPES` declares the population; duplicate basenames are
refused.

### The callsite driver missed five mutations

**Fix:** 18 → 26 checks. The first attempt at the last one asserted the `gh api`

did not try (removing CHECK1's contract comparison).

## Round 2 — briefed to attack round 1's corrections

**Commit reviewed (round 2):** `5d23bb89` — the tree WITH round 1's
corrections. That head is not an ancestor of the release commit because its
squash-merge discarded it; its tree is carried by `d9901b8d`.

**Gate potency: 18 mutations, 8 caught, 10 missed. Prose: 18 findings, ELEVEN
inside round 1's corrections.** The base rate held.

### Round 1 fixed freshness on the wrong module

The control shipped two adversaries differing in *two* bits — `PURE` is
(delegate no, verbatim yes), `DELEGATING` is (delegate yes, verbatim no) — and
**the (yes, yes) corner was never built.** Delegate any non-fixture compile to
the real binary, so the separate freshness probe is answered by a real compiler,
and replay *verbatim* recorded objects for the fixture, so the decode check,
`e_machine`, `compiled ⊆ symbols` and `declined ∩ symbols = {}` all pass on a
self-consistent recording. A stub compiling **nothing** about the fixture
produced `CHECKS=12/12`, `RESULT: PASS` through the real CI step.

**Fix:** the *fixture* carries the nonce now. Each run compiles a copy of
`falcon_opt_1318.wat` with one extra export named for that run, and the inspected
object must name it. A recording made before the run cannot contain it, so a
replay must **delegate** the fixture compile — and delegating it means compiling
it. "Replay forever" is closed by making the **input** unrepeatable, not by
adding another check on the output. Measured first: appending the export leaves
the decline matrix identical on all three legs.

**And round 1's regression test could not fail on the bug it named.** The
fixed-offset patcher, committed *as* that regression test, refuses in **both**
regimes — the recorded object's only symbols are `func_0` (6 bytes) and
`vbr_i32` (7), so no equal-length donor exists for a 26-byte name either. A
regression test that cannot fail on its own bug is worse than none, because it
reads as coverage.

**A structural consequence, recorded rather than hidden:** the fixture-nonce
check now *subsumes* the replay attacks, so no replay adversary can isolate the
decode check any more. Decode is therefore evidenced by driving `decode_text` on
both inputs, and labelled as the weaker evidence that is. The documented ARM
blindness is now a **pinned assertion** (filler scores 1.00 on ARM, 0.00 on
riscv) so it cannot quietly change.
