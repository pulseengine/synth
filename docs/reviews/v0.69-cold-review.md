`python3 scripts/loop_conformance_check.py v0.69.0` returned rc=1,
`verdict=DOES-NOT-CONFORM`. `RQ-69-ARCHMODEL` carried
`['process','carried','spar']`; every predecessor v0.63–v0.68 carries

survived the whole release, and `ci.yml` runs only the gate's unit tests, never
the gate. **Fixed:** tags restored, with the reason recorded in the artifact.
